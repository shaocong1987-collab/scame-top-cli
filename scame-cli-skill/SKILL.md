# SCAME-CLI 使用指南(给 agent)

单文件 Python CLI,数据来自 SCAME 选型工具线上站点:技术参数走公开层,
面价/库存是加密文件、用本机配置的授权码在本地解密。**你不需要理解加密细节,照命令用即可。**

## 环境要求(首次使用时检查)

```bash
python3 -c "from cryptography.hazmat.primitives.ciphers.aead import AESGCM" 2>/dev/null || pip3 install cryptography
```

授权码配置(查面价/库存/报价必需;技术参数查询不需要):
- 首选:`~/.scame-cli.json` 写 `{"password": "<授权码>"}`(让使用者本人填,agent 不要代填、不要询问具体码值)
- 或环境变量 `SCAME_DATA_PASSWORD`

## 命令(全部支持 --json,agent 一律加 --json 拿机器可读输出)

脚本路径:本 skill 目录下的 `scame_cli.py`(下述命令在 skill 目录执行,或用绝对路径)。

```bash
# 1. 查单型号完整技术参数(免授权)
python3 scame_cli.py info 213.1630 --json

# 2. 按参数搜型号(免授权;多个关键词是 AND 关系,可用:电流 63A、极数 3P+N+E、IP67、大类中文、系列名)
python3 scame_cli.py search 63A 3P+N+E IP67 --json --limit 10

# 3. 查面价(需授权码;只含《SCAME-TOP 常用面价表 2026》349 个常用型号,表外提示咨询商务)
python3 scame_cli.py price 213.1630 --json

# 4. 查库存(需授权码;available_quantity=可用数量)
python3 scame_cli.py stock 423.6367 --json

# 5. 简易报价:型号x数量 空格分隔多行项(需授权码)
python3 scame_cli.py quote 423.6367x166 423.3267x40 --json
```

退出码:`0` 成功;`1` 查无此型号;`2` 缺授权码;`3` 授权码不正确或已停用。
遇到 2/3 → 告诉用户"需要找管理员获取/更新授权码并配置到 ~/.scame-cli.json",不要重试猜码。

## 选型业务规则(向用户推荐型号时必须遵守)

1. **最终型号必须来自查询结果,严禁编造型号或参数**;参数不全先追问用户,不要硬猜。
2. 反向选型收敛顺序:产品形式 → 电流 → 极数 → 时钟位 h → 电压 → IP。
3. **IP 单向兼容**:客户要 IP44 可给 IP44/IP54;要 IP67 可给 IP66/IP67/IP69;
   **严禁向上替代**——客户要 IP44 时不得推荐 IP66/IP67/IP69(贵且过度)。
4. 极数标准化:3P+N+PE = 3P+N+E;三相五线/5 孔 → 3P+N+E;单相/3 孔 → 2P+E。
5. IEC 惯例推断(推断后要向用户确认):3P+N+E ↔ 6h ↔ 346-415V;2P+E ↔ 6h ↔ 200-250V。
6. 配套推荐(插头↔插座/连接器):电流/极数/时钟位/电压/IP 必须完全一致。
7. 大电流(899 系列,≥160A)注意核对**可接线径(电缆范围)**字段,报价前确认客户电缆截面积。
8. **防爆产品(产品大类=防爆,504/219/319/759/590/591/592/593/644/645/805 等系列)绝不自动选型**:
   必须先由人确认四件事——危险区域 Zone / 介质及组别(IIA-IIC / IIIA-IIIC)/ 温度等级 / 项目认证
   (ATEX/IECEx/CCC Ex)。缺任何一项只能给预选方向,不得输出最终防爆型号;成品禁止现场改装
   (开孔/加端子/换元件会导致认证失效);中国境内使用须按型号核查 CCC Ex。
   防爆面价一律"请咨询商务"(不在常用面价表)。

## 数据口径与红线

- 面价数据只含 349 个常用型号(2026-07 销售规则收敛),`price/quote` 查不到 = 不在常用面价表,
  一律回答"询价请咨询商务",**不要**替用户从旧价格表估价。
- `面价_pcs` 是官方吊牌价(list price),**不是成交价**;真实成交通常在面价基础上打折,
  折扣率是公司机密——**agent 绝不在任何输出里替用户估算或泄露折扣率**,报价口径由使用者本人把握。
- **面价、库存数值属公司机密**:只用于回答当前使用者的问题,不得写入对外文档/邮件/公开渠道;
  用户要发给客户的报价,提醒用"选型工具的报价单导出"(只含折后价,自动隐藏面价与折扣)。
- 库存为每周快照非实时,大单下单前提醒用户与仓库最终确认。
- 数据源站点如需变更,在 `~/.scame-cli.json` 加 `{"base": "https://新域名/"}`。
